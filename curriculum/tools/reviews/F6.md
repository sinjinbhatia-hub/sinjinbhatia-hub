## Findings

1. [low] notes.md §3.2 Definition 3.2 (and Definition 3.3) — "For admissible y and η and real ε, the
   function y + εη is again admissible" is false as written: admissible y is C², admissible η is only
   C¹ (as the bump function in Theorem 3.4 must be), so y + εη is C¹, not C². Definition 3.3 then
   compares J[y] only against "admissible ỹ", which would exclude the very competitors y + εη used
   two lines later to show that a minimum is stationary. — Fix: say y + εη is a C¹ curve with the
   right endpoints, and let Definition 3.3's competitors be C¹ functions with the same endpoints
   (J is defined on C¹ by Definition 3.1); Theorem 3.5 keeps its y ∈ C² hypothesis, which is where
   C² is actually used (step 2), and Exercise B3 is where that hypothesis is removed.
   Status: FIXED.
