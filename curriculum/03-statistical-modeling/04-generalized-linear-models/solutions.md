## A. Warm-up

**A1.** (a) With $y=Y/m$ and $Y = my$, $f(y) = \binom{m}{my}p^{my}(1-p)^{m-my} = \exp\{m[y\log\tfrac p{1-p} + \log(1-p)] + \log\binom m{my}\}$. Matching (3.1) with $a = 1/m$ (that is, $\phi=1$, $\omega=m$): $\theta = \log\frac p{1-p}$, $b(\theta) = -\log(1-p) = \log(1+e^\theta)$ (because $1-p = 1/(1+e^\theta)$), $c = \log\binom m{my}$.
(b) $\mathbb{E}\,y = b'(\theta) = e^\theta/(1+e^\theta) = p$ and $\mathrm{Var}(y) = a\,b''(\theta) = \frac1m\,p(1-p)$. For $m=10$, $p=0.3$: $0.21/10 = 0.021$, which equals $\mathrm{Var}(Y)/m^2 = 2.1/100$ ($Y\sim\mathrm{Bin}(10,0.3)$, checked with `scipy.stats.binom`).

**A2.** (a) $p(2) = \sigma(-3+1.6) = \sigma(-1.4) = 0.1978$; $p(3) = \sigma(-0.6) = 0.3543$.
(b) Odds: $0.1978/0.8022 = 0.2466$ and $0.3543/0.6457 = 0.5488$; the ratio is $2.2255 = e^{0.8}$.
(c) $\mathrm{RR} = 0.3543/0.1978 = 1.7913$ (smaller than the OR 2.2255, as (3.25) predicts). $\partial p/\partial x = \beta p(1-p) = 0.8\times0.3543\times0.6457 = 0.1830$.
(d) $p=\tfrac12$ when $-3+0.8x=0$, i.e. $x=3.75$. The marginal effect $\beta p(1-p)$ is largest at $p=\tfrac12$: $0.8/4 = 0.2$.

**A3.** Expected counts: dry $3.2e^{-2} = 3.2\times0.13534 = 0.4331$; wet $3.2e^{-1.5} = 3.2\times0.22313 = 0.7140$. The rate ratio is $e^{0.5} = 1.6487$ (and $0.7140/0.4331 = 1.6487$). The probability of no crash is $e^{-\mu}$: dry $e^{-0.4331} = 0.6485$, wet $e^{-0.7140} = 0.4897$.

**A4.** Unit deviances from (3.20), $d = 2[y\log(y/\mu)-(y-\mu)]$:

$D = 2.4+0.4470+1.3003 = 4.1473$. Deviance residuals $\mathrm{sign}(y-\mu)\sqrt d$: $-1.5492,\ -0.6686,\ +1.1403$. Pearson residuals $(y-\mu)/\sqrt\mu$: $-1.2/\sqrt{1.2} = -1.0954$; $-1.1/\sqrt{3.1} = -0.6248$; $2.6/\sqrt{4.4} = 1.2395$. $X^2 = 1.2+0.3903+1.5364 = 3.1267$, close to $D$ as Theorem 3.5's quadratic approximation says (and $\sum(r^D)^2 = D$, $\sum(r^P)^2 = X^2$).

**A5.** (a) With an intercept only, $\mu_i = e^\beta$ for every $i$, so $w_i = \mu_i = e^\beta$ (all equal) and $z_i = \beta + (y_i-e^\beta)/e^\beta$. The weighted least squares fit of a constant to $z$ is the weighted mean, and equal weights cancel: $\beta^{\rm new} = \bar z = \beta + (\bar y - e^\beta)/e^\beta = \beta+\bar y e^{-\beta}-1$.
(b) $\bar y = 4$. From $\beta=0$: $0+4-1 = 3$. From 3: $3+4e^{-3}-1 = 2+0.1991 = 2.1991$. From 2.1991: $2.1991+4e^{-2.1991}-1 = 1.6427$. (Continuing: $1.4165,\ 1.3867,\ 1.3863 = \log4$.) The first pass overshoots: the error $|\beta-\log4|$ goes from $1.39$ to $1.61$ (undamped Newton, as §3.4 warns). After that, far from the answer each pass removes about one unit because $\bar ye^{-\beta}$ is small, and near it the error is squared: the errors after passes 2 to 6 are $0.81,\ 0.26,\ 0.030,\ 4.5\times10^{-4},\ 10^{-7}$.
(c) At $\beta=\log\bar y$, $\bar ye^{-\beta} = 1$, so the pass returns $\beta$: the MLE is a fixed point, and it satisfies $\hat\mu=\bar y$, the moment equation (3.7).

## B. Core

**B1.** (a) Gamma: $V=\mu^2$; log link $g=\log\mu$, $g'=1/\mu$. The score (3.5) is $\frac1\phi\sum(y_i-\mu_i)x_i/(\mu_i^2\cdot\mu_i^{-1}) = \frac1\phi\sum(y_i-\mu_i)x_i/\mu_i$. The weights are $w_i = 1/(V g'^2) = 1/(\mu_i^2\mu_i^{-2}) = 1$. With $W=I$, (3.9) is $\beta^{\rm new} = (X^\top X)^{-1}X^\top z$: **ordinary least squares on the working response** $z_i = \eta_i+(y_i-\mu_i)/\mu_i$ at every pass.
(b) From $\beta=0$: $\mu=1$ and $z = 0+(y-1)/1 = (0,1,5)$, so $\beta^{(1)} = \bar z = 2$. The fixed point solves $\sum(y_i-\mu)/\mu = 0$ with common $\mu=e^\beta$, i.e. $\sum y_i/\mu = n$, so $\hat\mu = \bar y = 3$ and $\hat\beta = \log3 = 1.0986$ (confirmed by `glm_fit`; the weights are all 1).
(c) Log-link Poisson is canonical ($V g' = 1$), so the correct score is $\sum(y_i-\mu_i)x_i$ and the correct derivative of $\ell$ with respect to $\beta$ for one observation is $y-\mu$. Forgetting the factor $d\mu/d\eta = 1/g' = \mu$ in step 3 leaves $\sum(y_i-\mu_i)x_i/V(\mu_i) = \sum(y_i-\mu_i)x_i/\mu_i$. Test with $y=3$, $\mu=e^\beta$ at $\beta=1$ ($\mu=2.7183$): the true derivative is $y-\mu = 0.2817$ (a central difference of $\ell = y\beta-e^\beta-\log y!$ agrees); the wrong expression gives $0.2817/2.7183 = 0.1036$. The omission is invisible exactly when $g'=1$, the identity link: then $d\mu/d\eta = 1$, and a mistake in step 3 cannot show up. A test of your derivation on identity-link examples will therefore pass even if step 3 is wrong.

**B2.** (a) Count wins over the 16 (positive, negative) pairs. The 0.9 beats all four negatives: 4. Each 0.6 positive loses to 0.7, ties with 0.6 (counts $\tfrac12$), beats 0.2 and 0.1: $2.5$ each, 5 in total. The 0.3 positive loses to 0.7 and 0.6 and beats 0.2 and 0.1: 2. Total $11$, so $\mathrm{AUC} = 11/16 = 0.6875$.
(b) Sort scores downward: $0.9$ (P), $0.7$ (N), $0.6$ (P, P, N tied), $0.3$ (P), $0.2$ (N), $0.1$ (N). With $n_1=n_0=4$ the (FPR, TPR) vertices are $(0,0)$, $(0,\tfrac14)$, $(\tfrac14,\tfrac14)$, $(\tfrac12,\tfrac34)$ [the tied group moves diagonally], $(\tfrac12,1)$, $(\tfrac34,1)$, $(1,1)$. Trapezoid areas for the moves with positive width: $\tfrac14\times\tfrac14 = 0.0625$; $\tfrac14\times\tfrac{(1/4+3/4)}2 = 0.125$; $\tfrac14\times1 = 0.25$; $\tfrac14\times1 = 0.25$. Sum: $0.6875$. The code checks the vertices and the area.
(c) Sort by score downward and group ties. The ROC moves right by $1/n_0$ for each negative and up by $1/n_1$ for each positive; ties move diagonally. Area is accumulated only on rightward steps. Fix a negative $j$. If it is in a tie group, its horizontal step has height equal to (the TPR before the group) plus half the group's rise (the trapezoid average), so its area is $\frac1{n_0}\cdot\frac1{n_1}\big[\#\{i:y_i=1,s_i>s_j\}+\tfrac12\#\{i:y_i=1,s_i=s_j\}\big]$; if it is alone, the tie term is zero. Summing over the $n_0$ negatives gives $\frac1{n_1n_0}\sum_{i,j}[\mathbb{1}\{s_i>s_j\}+\tfrac12\mathbb{1}\{s_i=s_j\}]$, the Mann–Whitney $U/(n_1n_0)$. ∎
(d) $s\mapsto s^3$ is strictly increasing on positive $s$, so $\mathbb{1}\{s_i>s_j\}$ and $\mathbb{1}\{s_i=s_j\}$ are unchanged for every pair, so the sum is unchanged. Calibration is about the *values*: if $\hat p$ is calibrated, $\hat p^3$ is not (and conversely), yet both rank identically. In the project, $\hat p$ and $\hat p^3$ share AUC 0.8229 while the Hosmer–Lemeshow statistic is 9.60 versus 2639.

**B3.** (a) With $b=(-3.5,1)^\top$ and $s=(-1,-1,-1,1,1,1)$: $x_i^\top b = x_i-3.5 = (-2.5,-1.5,-0.5,0.5,1.5,2.5)$ and $s_ix_i^\top b = (2.5,1.5,0.5,0.5,1.5,2.5)>0$. By the proof of Theorem 3.4, $\ell(cb) = -\sum_i\log(1+e^{-ca_i})$ with $a_i = s_ix_i^\top b$, and (3.12) shows it strictly increases to 0 as $c\to\infty$. But $\ell(\beta)<0$ for every finite $\beta$, because each $\sigma(\cdot)<1$ makes every term negative. The supremum 0 is never attained, so no MLE exists.
(b) $X^\top X = \begin{pmatrix}6&21\\21&91\end{pmatrix}$ with $\det = 546-441=105$. At $\beta=0$, $w_i=\tfrac14$ and $z_i = 4y_i-2 = (-2,-2,-2,2,2,2)$, so $X^\top z = (0,\ 2(-1-2-3+4+5+6)) = (0,18)$. **B4.** (a) Split an exposure $t=t_1+t_2$ into two disjoint parts with the same rate $\lambda$. The counts $y_1\sim\mathrm{Pois}(t_1\lambda)$ and $y_2\sim\mathrm{Pois}(t_2\lambda)$ are independent, and the sum of independent Poissons is Poisson (F5): $y_1+y_2\sim\mathrm{Pois}((t_1+t_2)\lambda)$. So $\mathbb{E}\,y = t\lambda$: the mean is proportional to $t$. Taking logs, $\log\mu = \log t+\log\lambda = \log t+x^\top\beta$: the coefficient on $\log t$ is exactly 1.
(b) $z = (0.93-1)/0.06 = -1.167$, $p = 0.243$. The 95% interval $0.93\pm1.96(0.06) = [0.81,\ 1.05]$ contains 1. There is no evidence against proportionality of the mean to exposure, so the offset model (coefficient fixed at 1) is consistent with the data, and fixing it saves a parameter.
(c) Two failures. (i) Bias: if exposure is correlated with a predictor, that predictor's coefficient absorbs the exposure effect. (ii) Misfit and overdispersion: the variation of $t$ shows up as extra variance in the counts (in the project's simulation, deviance 651.7 without the offset against 399.9 with it), and the fitted model cannot be rescaled to a new exposure.

**B5.** (a) $\mathbb{E}\,y = \mathbb{E}[\mathbb{E}(y\mid\lambda)] = \mathbb{E}\lambda = \mu$ (Adam). Eve: $\mathrm{Var}(y) = \mathbb{E}[\mathrm{Var}(y\mid\lambda)]+\mathrm{Var}(\mathbb{E}[y\mid\lambda]) = \mathbb{E}\lambda+\mathrm{Var}\lambda = \mu+\mathrm{Var}\lambda$. A Gamma with shape $r$ and mean $\mu$ has rate $r/\mu$ and variance $r/(r/\mu)^2 = \mu^2/r$. So $\mathrm{Var}(y) = \mu+\mu^2/r$.
(b) $12.5 = 5+25/r$, so $r = 25/7.5 = 10/3 = 3.333$; the dispersion index is $2.5 = 1+\mu/r$.
(c) With the log link, $w = 1/(Vg'^2) = \mu^2/V$. Poisson (and quasi-Poisson): $V=\mu$, $w = \mu$: 5 at $\mu=5$, 50 at $\mu=50$. NB: $V=\mu+\mu^2/r$, $w = \mu/(1+\mu/r)$: $5/(1+1.5) = 2.0$ at $\mu=5$, $50/(1+15) = 3.125$ at $\mu=50$. The Poisson-to-NB weight ratio is $1+\mu/r$: 2.5 at $\mu=5$ and 16 at $\mu=50$. The NB downweights the large-count observations much more, because their variance is much larger than their mean; the weights stop growing once $\mu\gg r$ (they saturate at $r$).
(d) Quasi-Poisson multiplies each standard error by $\sqrt{\hat\phi} = \sqrt{2.5} = 1.581$.

**B6.** (a) From (3.20) with $y\in\{0,1\}$, $d(1,\hat\mu) = 2\log(1/\hat\mu)$ and $d(0,\hat\mu) = 2\log(1/(1-\hat\mu))$. With $\hat\mu=0.3$: $15\times2\log(1/0.3) + 35\times2\log(1/0.7) = 36.119+24.967 = 61.086$. (Equivalently $-2n[\hat p\log\hat p+(1-\hat p)\log(1-\hat p)]$.)
(b) $P(\chi^2_{49}>61.086) = 0.115$: the "test" says the model fits, at conventional levels.
(c) The shuffled data give $D=61.086$ again. By Theorem 3.6 (here $\hat\beta = \log\frac{0.3}{0.7}$ and $\hat p = 0.3$ for every case) $D$ depends on the data only through the fitted values, which depend only on the count of successes: 15 successes in the first 15 trials (a blatant trend), or scattered at random, give the identical statistic. **B7.** (a) $P(Y=1\mid x) = P(\varepsilon>-\eta) = 1-\sigma(-\eta) = 1-\frac{1}{1+e^\eta} = \frac{e^\eta}{1+e^\eta} = \sigma(\eta)$.
(b) $P(\varepsilon>-\eta) = 1-F(-\eta) = 1-\exp(-e^{\eta})$. Solve $\mu = 1-\exp(-e^\eta)$: $-\log(1-\mu) = e^\eta$, so $\eta = \log(-\log(1-\mu))$: the complementary log-log link.

**B8.** *Deviance.* With $V(t)=t^3$, (3.19): $d = 2\int_\mu^y(y-t)t^{-3}dt = 2\big[-\tfrac{y}{2t^2}+\tfrac1t\big]_\mu^y = 2\big[\tfrac{1}{2y}+\tfrac{y}{2\mu^2}-\tfrac1\mu\big] = \tfrac1y+\tfrac y{\mu^2}-\tfrac2\mu = \frac{(y-\mu)^2}{y\mu^2}$ (SymPy returns the same).
*Code.* Add to the dictionary: `FAMILIES["invgauss"] = dict(V=lambda m: m**3, dV=lambda m: 3*m**2, dev=lambda y, m: (y-m)**2/(y*m**2), default="log", phi_known=False, init=lambda y, om: y.astype(float), ll=...)` with `ll` the `scipy.stats.invgauss` log-density (mean $\mu$, $\lambda=1/\phi$ is `scale`). ## C. Challenge

**C1.** (a) Identity link: $g'=1$, $g''=0$. Poisson: $V=\mu$, $V'=1$. In (3.11), $V'g'+Vg'' = 1$ and $V^2g'^3 = \mu^2$, so $w^{\rm obs} = \frac1\mu+\frac{y-\mu}{\mu^2} = \frac{y}{\mu^2}$, while $w = 1/\mu$. (The code asserts this at the fitted values.)
(b) The fit is $\hat\beta = (1.9143,\ 2.6611)$. Errors $\|\beta_t-\hat\beta\|$ from $\beta=(1,1)$:
- Fisher: $1.8\times10^{-2},\ 6.6\times10^{-4},\ 2.5\times10^{-5},\ 9.2\times10^{-7},\ 3.4\times10^{-8},\ 1.3\times10^{-9},\dots$, a **linear** rate: each error is about 0.037 of the last.
- Newton: $1.1,\ 0.39,\ 4.8\times10^{-2},\ 6.7\times10^{-4},\ 1.1\times10^{-7},\ 10^{-15}$, a **quadratic** rate (each error about the square of the last, up to a constant: $0.048^2 = 2.3\times10^{-3}$, $(6.7\times10^{-4})^2 = 4.5\times10^{-7}$).

Both stop in 6 passes at the default tolerance. Fisher starts far closer: for the identity link a Fisher pass is a WLS regression of $y$ on $X$ with weights $1/\mu$, so it only has to learn the weights, and the first pass lands within 0.018. Newton must learn the full step. The rates differ because Fisher scoring drops the term $(y-\mu)(\dots)$ of (3.11): its contraction factor is the size of that dropped term relative to $X^\top WX$, about 0.04 for this good fit, whereas Newton's is exactly zero at the solution.
(c) Expected information: $\widehat{\mathrm{se}} = (0.3857,\ 0.3730)$. Observed information $\sum_i y_ix_ix_i^\top/\hat\mu_i^2$: $(0.3791,\ 0.3670)$. The two matrices differ by $\sum(y_i-\hat\mu_i)x_ix_i^\top/\hat\mu_i^2$, a sum of $n$ mean-zero terms whose total is $O(\sqrt n)$ against $O(n)$ for the information itself: here about 2%. They differ more in small samples or when the model fits badly (residuals large relative to $\sqrt V$).

**C2.** (a) $\log y = \log\mu+\log G$ with $G\sim\mathrm{Gamma}(\text{shape }\nu,\text{ rate }\nu)$. $\mathbb{E}[G^s] = \Gamma(\nu+s)/(\Gamma(\nu)\nu^s)$, and differentiating in $s$ at $0$: $\mathbb{E}\log G = \psi(\nu)-\log\nu$. So $\mathbb{E}\log y = \log\mu+\psi(\nu)-\log\nu$.
(b) OLS on $\log y$ estimates $\mathbb{E}[\log y\mid x] = (\beta_0+\psi(\nu)-\log\nu)+\beta_1x$: the slope is right and the intercept is shifted by $\psi(\nu)-\log\nu$ ($=-0.1758$ at $\nu=3$). $\exp(\text{fitted})$ estimates $\mu\,e^{\psi(\nu)-\log\nu} = 0.8388\,\mu$: it underestimates the mean by 16% (Jensen).
(c) Gamma/log GLM: $\hat\beta = (0.978,\ 0.521)$, $\hat\phi = 0.334$ (truth $1/\nu = 0.333$). OLS on $\log y$: $(0.793,\ 0.517)$, whose intercept is near $1-0.176 = 0.824$ and whose slope is right. $\overline{\exp(\text{OLS fit})}/\bar y = 0.8357$ against $e^{\psi(\nu)-\log\nu} = 0.8388$.
(d) For one observation, $\log f = \nu\log\frac{\nu y}\mu-\frac{\nu y}\mu-\log y-\log\Gamma(\nu)$. Differentiating in $\nu$: $\log\frac{\nu y}{\mu}+1-\frac y\mu-\psi(\nu)$. Summing, $n[\log\nu-\psi(\nu)]+\sum[\log\frac y\mu-\frac y\mu+1]$. By (3.20), $d = 2[-\log\frac y\mu+\frac y\mu-1]$, so the sum equals $-D/2$. Setting the derivative to zero: $\log\nu-\psi(\nu) = D/(2n)$. With $D = 184.009$ and $n=500$ the right side is $0.1840$, which gives $\hat\nu = 2.873$ (the Pearson estimate $1/\hat\phi$ is 2.991).

**C3.** (a) With $\mu_i = e^{x_i^\top\beta}$: $\ell(\beta,\pi) = \sum_{y_i=0}\log[\pi+(1-\pi)e^{-\mu_i}]+\sum_{y_i>0}[\log(1-\pi)+y_i\log\mu_i-\mu_i-\log y_i!]$. (The code uses the logit of $\pi$ as the free parameter.) It is not of the form (3.1) in any single parameter, because the zero cell has a different functional form from the rest.
(b) $\mathbb{E}\,y = \pi\cdot0+(1-\pi)\mu$. $\mathbb{E}\,y^2 = (1-\pi)(\mu+\mu^2)$. $\mathrm{Var}(y) = (1-\pi)(\mu+\mu^2)-(1-\pi)^2\mu^2 = (1-\pi)\mu+(1-\pi)\mu^2[1-(1-\pi)] = (1-\pi)\mu(1+\pi\mu)$. The ratio $\mathrm{Var}/\mathbb{E} = 1+\pi\mu>1$: overdispersed. (Numerical check at $\mu=2$, $\pi=0.3$: mean 1.4, variance $0.7\times2\times1.6 = 2.24$, by summing the PMF.)
