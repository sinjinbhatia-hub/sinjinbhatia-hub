# Brief: ML-3 — Linear models as machine learning: logistic and softmax regression, regularization, feature maps, generative vs discriminative, GDA, naive Bayes
Folder: curriculum/04-machine-learning/03-linear-models/ · ~10 hours · prereqs ML-2, ST-4 (logistic regression as a GLM), F5 (MVN) · unlocks ML-4, ML-5, ML-7
Pair with: Stanford CS229 notes §2–4 (classification, GLMs, generative learning); Bishop PRML ch. 4; Murphy *PML: An Introduction* ch. 9–10; Hastie, Tibshirani & Friedman ch. 4; Ng & Jordan, "On discriminative vs. generative classifiers" (NIPS 2001).
Conventions: features x ∈ R^d with x₀ = 1 for the bias; weights w (or θ); logistic σ(z) = 1/(1 + e^{−z}); softmax over K classes with logits z_k = w_kᵀx; one-hot labels; cross-entropy loss; feature map φ(x); regularization strength λ; class-conditional densities p(x|y) and priors π_k.

§1: Fisher's linear discriminant (1936) and Rosenblatt's perceptron (1958) were the first classifiers; logistic regression came from statistics (ST-4) and naive Bayes from information retrieval (Maron 1961); Ng and Jordan (2001) settled the generative-vs-discriminative question with a surprising answer (generative converges faster, discriminative to a lower error); the forcing problem: ML-1 said learning is minimizing risk over a hypothesis class; the simplest nontrivial class is linear functions of features, and almost everything in the course — kernels (ML-4), neural networks (ML-7), transformers (ML-9) — is a way of making the features better while keeping the last step linear. This module is where the student sees ST-3/ST-4's regression through ML's eyes: prediction, not inference. §2: a linear classifier is a hyperplane; logistic regression puts a sigmoid on the signed distance to turn it into a probability; softmax does the same for K hyperplanes at once and is SM-4's Boltzmann distribution over classes; a feature map bends the input space so a hyperplane in the new space is a curve in the old one; generative models describe each class's shape and then ask "which shape does this point fit better", discriminative models draw the boundary directly.

Topics in order: linear regression as ML (ST-3 recap in one page: the prediction view, the design matrix, closed form vs gradient descent — ML-2 — and when each is used; polynomial and other feature maps as still-linear models; the ridge solution as the regularized version); THE PERCEPTRON: the algorithm, its convergence theorem for separable data (prove — the classical margin argument; the bound (R/γ)² mistakes), its failure on non-separable data, its historical weight (and Minsky–Papert's XOR); LOGISTIC REGRESSION as ML: the model p(y=1|x) = σ(wᵀx), the decision boundary as a hyperplane, the log-loss/cross-entropy as the negative log-likelihood (ST-4) and as the KL divergence between the empirical and model distributions (F5 — derive), its convexity (ML-2 — derive the Hessian XᵀSX with S = diag(p(1−p)) ⪰ 0), the gradient Xᵀ(p − y) (LA-14 — the "prediction minus target" form that recurs in every model), gradient descent and Newton (= IRLS, ST-4) on it, the separable-data problem (weights diverge — regularization fixes it), the sigmoid's properties (σ' = σ(1 − σ), σ(−z) = 1 − σ(z), the logit as log-odds); SOFTMAX REGRESSION: the model, its derivation from the multinomial exponential family (ST-4) and as the Boltzmann distribution (SM-4/SM-7 — the "softmax temperature"), the cross-entropy loss and its gradient (LA-14's softmax Jacobian; the gradient is again p − y — derive), the redundancy of one weight vector (shift invariance of logits) and how to fix it, the decision regions as a Voronoi-like partition by hyperplanes (convex regions — prove), the log-sum-exp trick for numerical stability (LA-13-style: subtract the max; derive why it's exact); REGULARIZATION in ML terms: L2 (ridge — ST-3) as weight decay, the Bayesian view (ST-5's MAP), its effect on the margin and on separable data, L1 as feature selection (ST-3's lasso), early stopping as implicit regularization (state; ML-7), the regularization path and choosing λ by CV (ML-1), class imbalance and class weights; FEATURE ENGINEERING AND FEATURE MAPS: polynomial features and their combinatorial growth (C(d+p, p) — compute), interaction terms, one-hot encoding (ST-3), binning, radial basis function features (the Gaussian bump features — ML-4's kernels in disguise), the XOR problem solved by a feature map, the computational problem of explicit feature maps (motivating ML-4's kernel trick with the inner-product observation: the perceptron and logistic regression's predictions depend on x only through wᵀφ(x), and w = Σα_iφ(x_i) in the dual — derive the representer form for the perceptron), standardization and why it matters for regularized models (ST-3/ML-2); GENERATIVE CLASSIFIERS: the Bayes rule p(y|x) ∝ p(x|y)p(y) (F4), GAUSSIAN DISCRIMINANT ANALYSIS: class-conditional MVNs (F5) with shared covariance → linear decision boundary (derive that log p(y=1|x)/p(y=0|x) is linear in x, so GDA is logistic regression with a specific parametrization — CS229's key observation; derive the correspondence of parameters), the MLE for GDA's parameters (LA-14's MVN results — derive the class means, shared covariance, priors), quadratic discriminant analysis with separate covariances (the boundary becomes a conic — LA-8's quadratic forms), Fisher's linear discriminant as the direction maximizing between-class over within-class variance (derive via the generalized Rayleigh quotient — LA-8 and CM-6's generalized eigenproblem! — and show it coincides with GDA's boundary normal for two classes), LDA for dimensionality reduction (ML-6 preview); NAIVE BAYES: the conditional-independence assumption, the Bernoulli and multinomial models for text (bag of words), the MLE and the need for Laplace smoothing (derive the smoothed estimate as a Beta/Dirichlet posterior mean — ST-5), the log-linear decision rule (naive Bayes is also linear in the feature counts — derive), Gaussian naive Bayes, why it works despite the assumption being false (calibration is bad, ranking is often fine), spam filtering as the canonical example; GENERATIVE VS DISCRIMINATIVE: the Ng–Jordan result (generative needs O(log d) samples to approach its asymptotic error, discriminative O(d), but the discriminative asymptote is lower — state, explain the intuition, verify in the project), when each wins (small n, missing data, and semi-supervised → generative; large n and misspecification → discriminative), the hybrid view (every discriminative model is an implicit generative model's posterior — one paragraph); MULTICLASS STRATEGIES: one-vs-rest and one-vs-one for binary learners, vs native softmax, with the calibration and cost trade-offs; EVALUATION recap (ML-1's metrics applied; decision thresholds and the ROC curve as the family of thresholds; cost-sensitive thresholds derived from Bayes decision theory); a closing page: the linear model is the last layer of every deep network (ML-7), the kernel machine is a linear model in a huge feature space (ML-4), and attention is a softmax over similarities (ML-9) — the three forward links.

Worked examples (≥8): the perceptron run by hand on 4 points for one epoch; the logistic-regression gradient and Hessian for 3 data points, one Newton step from w = 0; softmax probabilities and the cross-entropy gradient p − y for one example with K = 3 (numbers); the polynomial feature count for d = 100, p = 3; GDA's parameters from a tiny two-class dataset and the resulting linear boundary, compared with logistic regression on the same data; Fisher's discriminant direction via the generalized eigenproblem for two 2D Gaussians; naive Bayes for spam on a 6-word vocabulary with Laplace smoothing, one classification by hand; the Bayes-optimal threshold for asymmetric misclassification costs.

§8 honest: "prediction minus target" as the gradient of every linear model is the pattern to memorize, and students re-derive it from scratch each time; softmax's shift invariance means the weights are not identifiable and gradient descent still works — that confuses people; generative models need the class-conditional density to be roughly right and discriminative models don't, which is the whole Ng–Jordan story; naive Bayes "works" in the sense of ranking, not probabilities — never trust its posteriors; Fisher's discriminant is CM-6's generalized eigenproblem and students who skipped CM-6 should go do it; feature engineering is where applied ML time goes, and this module can only show the mechanics.
