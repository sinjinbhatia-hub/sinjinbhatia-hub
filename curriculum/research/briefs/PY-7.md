# Brief: PY-7 — Matplotlib and scientific communication: figures that say something true
Folder: curriculum/00-python/07-matplotlib-and-communication/ · ~7 hours · prereqs PY-6 · unlocks every figure in the curriculum; take it before CM-1's project
Pair with: the Matplotlib "Quick start guide" and "Artist tutorial" (matplotlib.org); Rougier, *Scientific Visualization: Python + Matplotlib* (free, 2021) ch. 1–4; VanderPlas, *Python Data Science Handbook* 2e ch. 4; Tufte, *The Visual Display of Quantitative Information* ch. 1–2 (reference; the principles); Crameri, Shephard & Heron, "The misuse of colour in science communication", *Nature Communications* 2020 (why not jet); Wilke, *Fundamentals of Data Visualization* (free online) selected chapters on axes, color, and uncertainty.
Conventions: `import matplotlib.pyplot as plt`; the object-oriented API always — `fig, ax = plt.subplots()` then `ax.plot(...)`; never the implicit `plt.plot` state machine in scripts; `fig.savefig("figures/name.png", dpi=150, bbox_inches="tight")`; headless via `MPLBACKEND=Agg`; perceptually uniform colormaps (viridis, cividis, magma) by default; every axis labeled with units; third-party imports: numpy, matplotlib, scipy (for a KDE and a fit in the project).

Read the PY addendum in research/WRITER-BRIEF.md first.

§1 (the problem): every module in this curriculum ends with a figure, and a figure with the wrong axis scale hides the result — a convergence that is O(h²) is invisible on linear axes and a straight line of slope 2 on log-log. The forcing problem: you have the PY-5 integrator errors for ten step sizes and need one picture that proves the order of convergence to someone skeptical. Making that picture requires knowing what a Figure and an Axes are, how scales and ticks work, and what makes a plot honest. §2 (the intuition): a Figure is the canvas; an Axes is one plot on it with its own x and y Axis objects; everything drawn is an Artist with properties you can set; `plt.subplots` hands you the two objects you need and you talk to them directly — the pyplot "current figure" magic is for the REPL only.

Topics in order: the object model — Figure, Axes, Axis, Artist, `fig, ax = plt.subplots()`, `fig, axs = plt.subplots(2, 3, figsize=..., sharex=...)`, why the OO API (multiple figures, functions that take an `ax`); basic plots with the arguments that matter — `plot` (markers, linestyles, `label`), `scatter` (size and color arrays, `alpha`), `bar`/`barh`, `hist` (bins, `density=True`, range), `errorbar` (`yerr`, `capsize`, `fmt`), `fill_between` for uncertainty bands, `imshow` (`origin`, `extent`, `aspect`, interpolation off), `pcolormesh` vs `imshow`, `contour`/`contourf` with labeled levels, `quiver` and `streamplot` for vector fields (EM-1, CM-1), `step`, `stem`; scales — `set_xscale("log")`, `loglog`, `semilogy`, symlog, and reading slopes off log-log plots (the convergence-plot recipe with a fitted line and a slope annotation); axes control — limits, ticks and `ticker` (MultipleLocator, FuncFormatter for π multiples), tick labels, grid, `set_aspect("equal")` for geometry, inverting axes, twin axes (`twinx`) and when they mislead; text — labels with units, titles, `legend` placement (`loc`, `ncol`, outside the axes), `annotate` with arrows, `text` with `transform=ax.transAxes`, mathtext (`r"$\alpha$"`) without LaTeX installed; color — colormaps (sequential, diverging, cyclic; `viridis` vs `jet` on the same data to show the artifacts), `Normalize`/`LogNorm`, colorbars (`fig.colorbar(im, ax=ax)`), the default color cycle and setting one, color-blind safety (Okabe–Ito palette); layout — `constrained_layout=True`, `gridspec` for unequal panels, inset axes, `fig.suptitle`, small multiples; styles — `plt.style.use`, `rcParams`, a house style dict for the course; saving — formats (PNG for raster, PDF/SVG for vector), `dpi`, `bbox_inches="tight"`, `transparent`; 3D in one paragraph (`projection="3d"`, surface, when 2D with color is better); animation — `FuncAnimation`, saving frames or a GIF with `PillowWriter` (fallback to a frame strip when no writer is available); what makes a figure honest — axis starting points, aspect ratio and perceived slope, truncated axes, dual axes, error bars that mean something (state what: SD, SE, CI), overplotting (`alpha`, hexbin), the one-message rule, labeling directly vs legends; reading data for plots — `np.loadtxt`, `csv`, JSON (PY-2).

Build-it-yourself sequences: (1) from `plt.plot(x, y)` to a function `plot_convergence(ax, h, err, order)` that draws data, a reference slope line, and an annotation, used on PY-5's trapezoid and Simpson errors; (2) the same data on linear, semilog, log-log axes — see what each reveals; (3) a phase portrait of the pendulum: `quiver` on a grid, then `streamplot`, then trajectories from `solve_ivp` overlaid (CM-1 preview); (4) `viridis` vs `jet` on a smooth 2D function, with a line profile showing the false edges jet creates; (5) a `plot_helpers.py` module with the house style, a `savefig` wrapper that creates `figures/`, and `add_slope_guide(ax, order)`, which later curriculum modules may import by copying; (6) six-panel small multiples with shared axes and one colorbar; (7) a pendulum animation saved headless.

Worked examples (≥6): anatomy of a figure with every Artist labeled (a figure that labels itself); the convergence plot with slopes 2 and 4 annotated; a histogram with `density=True` and a fitted Gaussian plus a scipy KDE overlaid (F4); an `errorbar` plot of Monte Carlo estimates vs sample size with 1/√n guide (F5); `imshow` vs `pcolormesh` of a 2D potential with contour overlay (EM-2); a two-panel figure where the top uses a truncated y-axis and the bottom does not, with a sentence on which claim each supports.

Project: `plot_helpers.py` plus project.py reproducing seven canonical scientific figures saved to `figures/`: the convergence plot (slopes asserted from a fit within 0.1 of 2 and 4); the pendulum phase portrait with `streamplot` and three overlaid trajectories (energy conservation of the integrated trajectories asserted to 1e-6 relative, using `solve_ivp` with a tight tolerance); the histogram-with-fit; the Monte Carlo error-bar plot (fitted slope −0.5 ± 0.05 on log-log); the 2D potential heatmap with contours and a correctly oriented colorbar (`origin`/`extent` asserted by checking a known point maps to the right pixel); a six-panel small-multiples grid of damped oscillators with shared axes; the jet-vs-viridis comparison with a profile. "Your turn": restyle one figure for a slide (bigger fonts, fewer ticks) and one for a paper (vector PDF); add an inset zoom; make a figure deliberately misleading and then fix it, stating the misleading claim; plot the PY-6 random-walk MSD with its guide line.

§8 honest: the pyplot state machine (`plt.plot`, `plt.xlabel`) works until you have two figures, and then nothing is where you think — switch to `ax` now; `imshow` puts the origin at the top left and your physics has it at the bottom left — `origin="lower"` and `extent` every time; log axes with zero or negative data vanish silently; `tight_layout` vs `constrained_layout` fights will waste your time — pick constrained; a legend is a failure of direct labeling that we tolerate; jet is still the default in people's heads; a figure that needs a paragraph to explain has two messages — split it; headless saving (`Agg`) is what the curriculum requires and `plt.show()` in a script will hang or do nothing.
