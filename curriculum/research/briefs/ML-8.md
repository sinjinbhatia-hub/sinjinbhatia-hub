# Brief: ML-8 — Architectures: convolution and its link to Fourier, CNNs, recurrent networks, residual connections, training dynamics

Conventions: input tensors as (batch, channels, height, width) — N×C×H×W; kernel size k, stride s, padding p, dilation; output size ⌊(H + 2p − k)/s⌋ + 1; cross-correlation (what DL calls "convolution") vs true convolution (the flip); feature maps; receptive field; RNN hidden state h_t = φ(W_hh h_{t−1} + W_xh x_t + b); LSTM gates (f, i, o) and cell c_t; residual block y = x + F(x); BPTT = backpropagation through time.

§1: Hubel and Wiesel (1959–62) found that visual-cortex neurons respond to local oriented edges and that complex cells pool over position; Fukushima's Neocognitron (1980) built that into a network; LeCun (1989, 1998) trained it with backprop and read zip codes with it; Krizhevsky, Sutskever and Hinton's AlexNet (2012) won ImageNet by 10 points and started the deep-learning era; Elman (1990) and Hochreiter & Schmidhuber (1997) built networks with memory for sequences; He et al. (2015) found that identity shortcuts let networks go from 20 to 1000 layers. The forcing problem: ML-7's MLP treats an image as an unstructured vector, so it has to learn translation invariance separately at every pixel position (a 1000×1000 image into a 1000-unit layer is 10⁹ parameters); a sequence of arbitrary length can't even be fed to an MLP; the solution in both cases is to build the structure of the data — translation symmetry for images, temporal ordering for sequences — into the architecture by sharing weights, and the mathematics of weight sharing is F3's convolution. §2: a convolutional layer slides a small filter across the image and applies the same weights everywhere — it is F3's convolution, and F3 said convolution is multiplication by a circulant (Toeplitz) matrix, so a conv layer is a linear layer with a very constrained weight matrix (LA-4); stacking convs and pooling builds features of increasing abstraction and receptive field; a recurrent network applies the same weights at every time step, so backprop through time multiplies the same Jacobian many times (LA-7's matrix powers), which is why gradients vanish or explode and why LSTMs add a gated highway; a residual connection adds the identity, which keeps every Jacobian near I and makes depth trainable.

§8 honest: "convolution" in deep learning is cross-correlation and the flip matters only when you connect it to F3 — connect it anyway, the circulant/DFT view is the one real theorem here; im2col and the output-size formula are where every implementation bug lives; the conv backward pass is an exercise in indices that is worth doing once by hand; residual connections are the single most important architectural idea of the decade and the Jacobian argument is three lines; BPTT's gradient product is LA-7's matrix powers and the student who skipped LA-7 will not understand why LSTMs exist; LSTMs are historically essential and practically superseded by ML-9's transformers — learn them for the ideas (gating, the additive highway), not the recipe; adversarial examples are a real property of these models and not a curiosity; the training-dynamics page is empirical folklore with partial theory.
