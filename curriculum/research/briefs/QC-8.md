# Brief: QC-8 — Quantum error correction: repetition and Shor codes, the stabilizer formalism, the Steane code, the surface code, the threshold theorem
Folder: curriculum/05-quantum-computing/08-quantum-error-correction/ · ~16 hours · prereqs QC-7 (channels, Pauli errors, twirling, fidelity), QC-2 (Clifford group, Gottesman–Knill, CNOT circuits), LA-3 (linear algebra over GF(2) — QC-4 used it), LA-12 (tensor products) · unlocks QC-9's fault-tolerance context; the capstone of the quantum-computing theory
Pair with: Mermin ch. 5; Nielsen & Chuang ch. 10; Gottesman's thesis "Stabilizer Codes and Quantum Error Correction" (1997, arXiv quant-ph/9705052) ch. 1–3 and his "An introduction to quantum error correction and fault-tolerant quantum computation" (arXiv 0904.2557) — read the latter; Preskill ch. 7; Fowler, Mariantoni, Martinis & Cleland, "Surface codes: towards practical large-scale quantum computation" (arXiv 1208.0928) §I–V; Google Quantum AI, "Quantum error correction below the surface code threshold" (Nature 2024/2025) as the current experimental milestone; Dennis, Kitaev, Landahl & Preskill (2002) for the threshold-as-phase-transition picture (SM-6 link).
Conventions: n physical qubits encode k logical qubits; [[n, k, d]] code with distance d (corrects ⌊(d−1)/2⌋ arbitrary errors); the Pauli group P_n (n-fold tensor products of {I, X, Y, Z} with phases ±1, ±i); stabilizer group S ⊂ P_n abelian, −I ∉ S; generators g_1..g_{n−k}; code space = simultaneous +1 eigenspace; syndrome = vector of generator eigenvalues (±1 ↔ bits); logical operators X̄, Z̄ in N(S) \ S; check matrix in binary symplectic form [H_X | H_Z]; X-type and Z-type stabilizers for CSS codes; physical error rate p; logical error rate p_L; threshold p_th; the surface code distance d on a d×d patch (rotated layout); Y = iXZ.

§1: in 1995 most physicists believed quantum computers were impossible — errors are continuous, measurement destroys the state, and no-cloning forbids redundancy (QC-2); Shor (1995) found a 9-qubit code that corrects any single-qubit error anyway, and Steane (1996) a 7-qubit one; Calderbank, Shor and Steane built CSS codes from classical codes; Gottesman (1996–97) invented the stabilizer formalism that turned QEC into group theory over GF(2); Aharonov–Ben-Or, Kitaev, Knill–Laflamme–Zurek (1996–97) proved the threshold theorem — below some physical error rate, arbitrarily long computations are possible with polylogarithmic overhead; Kitaev (1997) invented the toric code, whose planar version (the surface code) has the highest threshold (~1%) with only nearest-neighbor gates; in 2024 Google showed a distance-7 surface-code memory whose logical error rate falls as the distance grows — the first experiment below threshold. The forcing problem: QC-7 showed that every gate and every idle moment corrupts the state; QC-5's Shor algorithm for RSA needs ~10⁹–10¹⁰ logical operations; with physical error rates ~10⁻³, nothing works without error correction, and error correction must solve three apparent impossibilities at once: copy without cloning, measure without collapsing the data, and fix continuous errors with discrete operations. §2: redundancy without cloning: encode one logical qubit in an entangled state of many physical qubits (α|000⟩ + β|111⟩ is not three copies of α|0⟩ + β|1⟩); measure only parities (is qubit 1 equal to qubit 2?) which reveal where an error happened but nothing about α, β; continuous errors are discretized by the syndrome measurement itself, because any single-qubit error is a linear combination of I, X, Y, Z (QC-1's Pauli basis) and the measurement projects onto one of them; a stabilizer code is defined by a set of commuting Pauli checks, the code space is where all checks read +1, errors are Paulis that anticommute with some checks, and the syndrome is which checks flip — all of it is linear algebra over GF(2); the surface code is a checkerboard of 4-qubit X and Z checks on a 2D grid whose logical operators are strings across the patch, so a logical error needs a chain of errors spanning the grid — and below threshold, long chains are exponentially unlikely (SM-6's ordered phase).

§8 honest: the discretization theorem is the single idea that makes QEC possible and is routinely rushed — work the small-rotation example until it's obvious why measuring the syndrome makes a continuous error discrete; the stabilizer formalism is linear algebra over GF(2) with a symplectic twist, and students who skipped QC-4's GF(2) elimination will struggle; error propagation through CNOTs (X forward, Z backward) is the rule behind every fault-tolerance design — memorize it; Eastin–Knill means the T gate is always the expensive part, and magic-state distillation is a large fraction of real resource estimates; surface-code decoding by matching is an algorithm the project only approximates for small d, and the thresholds measured here depend on the decoder and noise model — always state both; "below threshold" was demonstrated for a memory in 2024, not for computation, and the module is careful about that distinction; this is the hardest module in the quantum-computing course — budget the full 16 hours and expect to reread the stabilizer sections.
