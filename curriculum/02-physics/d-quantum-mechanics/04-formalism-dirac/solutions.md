## A. Warm-up

**A1.** (a) The bra conjugates the components: $\langle\phi| = \frac{1}{\sqrt2}(-i, 1)$. So
$\langle\phi|\psi\rangle = \frac{1}{\sqrt{10}}\big((-i)(1) + (1)(2i)\big) = \frac{i}{\sqrt{10}}$, and $\langle\psi| = \frac{1}{\sqrt5}(1, -2i)$ gives $\langle\psi|\phi\rangle = \frac{1}{\sqrt{10}}(i - 2i) = -\frac{i}{\sqrt{10}}$, the conjugate.

(b) Column times row:
$$\hat M = |\psi\rangle\langle\phi| = \frac{1}{\sqrt{10}}\begin{pmatrix}1\\2i\end{pmatrix}\begin{pmatrix}-i & 1\end{pmatrix} = \frac{1}{\sqrt{10}}\begin{pmatrix}-i & 1\\ 2 & 2i\end{pmatrix}.$$
$\hat M|\phi\rangle = |\psi\rangle\langle\phi|\phi\rangle = |\psi\rangle$; in components $\frac{1}{\sqrt{20}}\big((-i)(i) + 1, 2i + 2i\big) = \frac{1}{\sqrt{20}}(2, 4i) = \frac{1}{\sqrt5}(1, 2i)$ ✓. $\operatorname{Tr}\hat M = \frac{-i + 2i}{\sqrt{10}} = \frac{i}{\sqrt{10}} = \langle\phi|\psi\rangle$. In general $\operatorname{Tr}(|\psi\rangle\langle\phi|) = \sum_n\langle n|\psi\rangle\langle\phi|n\rangle = \langle\phi|\big(\sum_n|n\rangle\langle n|\big)|\psi\rangle = \langle\phi|\psi\rangle$ by (3.3).

(c) $\hat M^\dagger$ is the conjugate transpose: $\frac{1}{\sqrt{10}}\begin{pmatrix}i & 2\\ 1 & -2i\end{pmatrix}$. And $|\phi\rangle\langle\psi| = \frac{1}{\sqrt{10}}\begin{pmatrix}i\\1\end{pmatrix}\begin{pmatrix}1 & -2i\end{pmatrix} = \frac{1}{\sqrt{10}}\begin{pmatrix}i & 2\\ 1 & -2i\end{pmatrix}$ ✓.

**A2.** (a) For all $\phi, \psi$: $\langle\phi|\hat A\hat B\psi\rangle = \langle\hat A^\dagger\phi|\hat B\psi\rangle = \langle\hat B^\dagger\hat A^\dagger\phi|\psi\rangle$, applying (3.9) first to $\hat A$ (with ket $\hat B\psi$), then to $\hat B$. By uniqueness of the adjoint, $(\hat A\hat B)^\dagger = \hat B^\dagger\hat A^\dagger$. Next, $\langle\phi|\hat A|\psi\rangle^* = \langle\phi|\hat A\psi\rangle^* = \langle\hat A\psi|\phi\rangle$ by (3.1), and $\langle\hat A\psi|\phi\rangle = \overline{\langle\phi|\hat A\psi\rangle}$... more directly: $\langle\psi|\hat A^\dagger\phi\rangle = \langle\hat A^{\dagger\dagger}\psi|\phi\rangle = \langle\hat A\psi|\phi\rangle = \overline{\langle\phi|\hat A\psi\rangle}$, using $\hat A^{\dagger\dagger} = \hat A$ (apply (3.9) twice) and conjugate symmetry.

(b) With $\hat A^\dagger = \hat A$, $\hat B^\dagger = \hat B$:
- $(\hat A\hat B)^\dagger = \hat B\hat A$: Hermitian iff $[\hat A, \hat B] = 0$.
- $[\hat A, \hat B]^\dagger = \hat B\hat A - \hat A\hat B = -[\hat A, \hat B]$: anti-Hermitian, not Hermitian unless zero.
- $(i[\hat A, \hat B])^\dagger = \bar i\,(-[\hat A, \hat B]) = (-i)(-1)[\hat A, \hat B] = i[\hat A, \hat B]$: Hermitian.
- $(\hat A\hat B + \hat B\hat A)^\dagger = \hat B\hat A + \hat A\hat B$: Hermitian.

(c) $\langle\psi|\hat A^\dagger\hat A|\psi\rangle = \langle\hat A^{\dagger\dagger}\psi|\hat A\psi\rangle = \langle\hat A\psi|\hat A\psi\rangle = \|\hat A\psi\|^2\ge0$.

**A3.** (a) $\hat P_n\hat P_m = |n\rangle\langle n|m\rangle\langle m| = \delta_{nm}|n\rangle\langle m| = \delta_{nm}\hat P_n$. $(|n\rangle\langle n|)^\dagger = |n\rangle\langle n|$ by the rule $(|\alpha\rangle\langle\beta|)^\dagger = |\beta\rangle\langle\alpha|$.

(b) If $\hat P|v\rangle = \lambda|v\rangle$ with $|v\rangle\ne0$, then $\lambda|v\rangle = \hat P|v\rangle = \hat P^2|v\rangle = \lambda^2|v\rangle$, so $\lambda^2 = \lambda$ and $\lambda\in\{0, 1\}$.

(c) $\operatorname{Tr}\hat P_n = \langle n|n\rangle = 1$ by A1(b), so $\sum_n\operatorname{Tr}\hat P_n = N$; equivalently $\operatorname{Tr}\hat 1 = N$ with (3.3). By (3.10) and linearity of the trace, $\operatorname{Tr}\hat Q = \sum_nq_n\operatorname{Tr}\hat P_n = \sum_nq_n$.

**A4.** (a) By (3.14), $[\hat x, \hat p^2] = [\hat x, \hat p]\hat p + \hat p[\hat x, \hat p] = 2i\hbar\hat p$. And $[\hat x^2, \hat p] = -[\hat p, \hat x\hat x] = -([\hat p, \hat x]\hat x + \hat x[\hat p, \hat x]) = -(-2i\hbar\hat x) = 2i\hbar\hat x$.

(b) $n = 1$ is $[\hat x, \hat p] = i\hbar$. If $[\hat x, \hat p^n] = i\hbar n\hat p^{n-1}$, then $[\hat x, \hat p^{n+1}] = [\hat x, \hat p^n\hat p] = [\hat x, \hat p^n]\hat p + \hat p^n[\hat x, \hat p] = i\hbar n\hat p^n + i\hbar\hat p^n = i\hbar(n + 1)\hat p^n$. For $f(p) = \sum_kf_kp^k$, linearity gives $[\hat x, f(\hat p)] = \sum_kf_ki\hbar k\hat p^{k-1} = i\hbar f'(\hat p)$. (SymPy checks $n = 3$ on a test function.)

(c) $\{x, p^n\} = \frac{\partial x}{\partial x}\frac{\partial p^n}{\partial p} - \frac{\partial x}{\partial p}\frac{\partial p^n}{\partial x} = np^{n-1}$. The dictionary (3.15) predicts $\frac{1}{i\hbar}[\hat x, \hat p^n] = n\hat p^{n-1}$: exact agreement, with no ordering ambiguity because only $\hat p$'s appear.

**A5.** (a) The $3\times3$ block structure: $e_3$ is an eigenvector with eigenvalue $3$. The upper block $\begin{pmatrix}2&i\\-i&2\end{pmatrix}$ has characteristic polynomial $(2 - q)^2 - (i)(-i) = (2 - q)^2 - 1$, roots $q = 1, 3$. For $q = 1$: $(1, i)$, since $2 + i\cdot i = 1$ and $-i + 2i = i$. For $q = 3$: $(1, -i)$, since $2 + i(-i) = 3$ and $-i - 2i = -3i$. Orthonormal eigenbasis:
$|1\rangle = \frac{1}{\sqrt2}(1, i, 0)$, $|3, a\rangle = \frac{1}{\sqrt2}(1, -i, 0)$, $|3, b\rangle = (0, 0, 1)$. The eigenvalue $3$ is doubly degenerate.

(b) $\langle1|\psi\rangle = \frac{1}{\sqrt6}(1\cdot1 + (-i)\cdot1) = \frac{1 - i}{\sqrt6}$, so $P(1) = \frac{2}{6} = \frac13$. $\langle3, a|\psi\rangle = \frac{1 + i}{\sqrt6}$ and $\langle3, b|\psi\rangle = \frac{1}{\sqrt3}$, so $P(3) = \frac26 + \frac13 = \frac23$. After outcome $1$ the state is $|1\rangle$ (up to phase). After outcome $3$, by (3.12): $\hat P_3|\psi\rangle = |\psi\rangle - |1\rangle\langle1|\psi\rangle = \frac{1}{\sqrt3}(1, 1, 1) - \frac{1 - i}{2\sqrt3}(1, i, 0) = \frac{1}{\sqrt3}\big(\frac{1 + i}{2}, \frac{1 - i}{2}, 1\big)$, of squared norm $\frac13(\frac12 + \frac12 + 1) = \frac23 = P(3)$ ✓. Normalized: $\frac{1}{\sqrt2}\big(\frac{1 + i}{2}, \frac{1 - i}{2}, 1\big) = (0.3536 + 0.3536i,\ 0.3536 - 0.3536i,\ 0.7071)$. Note it is *not* either basis vector of the eigenspace: collapse keeps the state's component within the eigenspace intact.

(c) $\langle Q\rangle = 1\cdot\frac13 + 3\cdot\frac23 = \frac73$. Directly, $\langle\psi|\hat Q|\psi\rangle = \frac13\sum_{jk}Q_{jk} = \frac13(2 + i - i + 2 + 3) = \frac73$ ✓. $\langle Q^2\rangle = \frac13 + 9\cdot\frac23 = \frac{19}{3}$, $\sigma_Q^2 = \frac{19}{3} - \frac{49}{9} = \frac89$, $\sigma_Q = \frac{2\sqrt2}{3} = 0.9428$.

(d) Any other orthonormal basis of $E_3$ is $|3, a'\rangle$, $|3, b'\rangle$ with $(|3, a'\rangle\ |3, b'\rangle) = (|3, a\rangle\ |3, b\rangle)W$ for a $2\times2$ unitary $W$. The projector $\sum_i|3, i'\rangle\langle3, i'| = (\ldots)WW^\dagger(\ldots)^\dagger = \sum_i|3, i\rangle\langle3, i|$ is unchanged, and both $P(3) = \langle\psi|\hat P_3|\psi\rangle$ and the state $\hat P_3|\psi\rangle/\|\cdot\|$ depend only on $\hat P_3$.

## B. Core

**B1.** (a) $\hat A\hat B$ multiplies row $i$ of $\hat B$ by $A_{ii}$; $\hat B\hat A$ multiplies column $j$ by $A_{jj}$. $\hat B$'s nonzero entries are at $(1,2)$, $(2,1)$, $(3,3)$, and for each $A_{ii} = A_{jj}$ ($1 = 1$, $1 = 1$, $2 = 2$). So $\hat A\hat B = \hat B\hat A$.

(b) $\hat A$ is diagonal, so $e_1, e_2, e_3$ are its eigenvectors. But $\hat Be_1 = e_2$, not a multiple of $e_1$. Theorem 3.6(b)'s last step ("the eigenspace is one-dimensional, so $\hat B|a\rangle = b|a\rangle$") fails: $\hat Be_1$ does lie in $\hat A$'s $a = 1$ eigenspace, $\operatorname{span}(e_1, e_2)$, as the first step promises, but that space is two-dimensional.

(c) Following Theorem 3.6(c): restrict $\hat B$ to $E_1 = \operatorname{span}(e_1, e_2)$, where it is $\begin{pmatrix}0&1\\1&0\end{pmatrix} = \sigma_x$, with eigenvectors $(1, \pm1)/\sqrt2$ and eigenvalues $\pm1$. On $E_2 = \operatorname{span}(e_3)$, $\hat Be_3 = 5e_3$. Common basis and joint eigenvalues:
$\frac{1}{\sqrt2}(1, 1, 0)$: $(1, 1)$; $\frac{1}{\sqrt2}(1, -1, 0)$: $(1, -1)$; $(0, 0, 1)$: $(2, 5)$.
The three pairs are distinct, so $(a, b)$ labels each basis vector uniquely: $\{\hat A, \hat B\}$ is a complete set of commuting observables on $\mathbb C^3$. ($\hat A$ alone is not, since $a = 1$ appears twice.)

**B2.** (a) Steps 1, 2 and 4 of Theorem 3.7 are unchanged: $\sigma_A^2\sigma_B^2\ge|\langle f|g\rangle|^2 = (\operatorname{Re}\langle f|g\rangle)^2 + (\operatorname{Im}\langle f|g\rangle)^2$. From step 4, $\langle f|g\rangle = \langle\hat A\hat B\rangle - \langle A\rangle\langle B\rangle$ and $\overline{\langle f|g\rangle} = \langle\hat B\hat A\rangle - \langle A\rangle\langle B\rangle$. So
$\operatorname{Re}\langle f|g\rangle = \frac12(\langle f|g\rangle + \overline{\langle f|g\rangle}) = \frac12\langle\{\hat A, \hat B\}\rangle - \langle A\rangle\langle B\rangle$, and $\operatorname{Im}\langle f|g\rangle = \frac{1}{2i}\langle[\hat A, \hat B]\rangle$ as before. Substituting gives the inequality. ∎

(b) $\langle x\rangle = 0$ ($|\psi|^2$ is even) and $\langle p\rangle = 0$ (QM-2 B5). Write $\psi' = (-\frac{x}{2a^2} + 2icx)\psi$. Then $\langle\hat x\hat p\rangle = \int\bar\psi\,x(-i\hbar)\psi'\,dx = -i\hbar\int\big(-\frac{x^2}{2a^2} + 2icx^2\big)|\psi|^2dx = -i\hbar\big(-\frac{1}{2a^2} + 2ic\big)\langle x^2\rangle = \big(\frac{i\hbar}{2a^2} + 2\hbar c\big)a^2 = \frac{i\hbar}{2} + 2\hbar ca^2$. Since $\hat p\hat x = \hat x\hat p - i\hbar$, $\langle\hat p\hat x\rangle = -\frac{i\hbar}{2} + 2\hbar ca^2$, and
$$\tfrac12\langle\{\hat x, \hat p\}\rangle - \langle x\rangle\langle p\rangle = 2\hbar ca^2.$$
Right side of (a): $(2\hbar ca^2)^2 + (\hbar/2)^2 = \frac{\hbar^2}{4}(1 + 16c^2a^4)$. Left side: $\sigma_x^2\sigma_p^2 = \frac{\hbar^2}{4}(1 + 16c^2a^4)$. Equal for every $c$. For $c\ne0$, $\sigma_x\sigma_p > \hbar/2$: the chirp builds a position–momentum correlation, and Robertson's bound, which throws the correlation away, is not tight.

(c) $a = 1$, $c = -\frac14$, $\hbar = 1$: $\sigma_x\sigma_p = \frac12\sqrt{1 + 1} = 0.70711$, so the left side is $0.5$. Covariance $= 2(-\frac14) = -0.5$, so the right side is $0.25 + 0.25 = 0.5$ ✓. (The project computes $\sigma_x$, $\sigma_p$ and the covariance on the grid.)

**B3.** (a) Take $\langle\psi|$ of the eigen-equation: $\langle A\rangle - i\lambda\langle B\rangle = \mu$. Both $\langle A\rangle$ and $\langle B\rangle$ are real (Hermitian), and $\lambda$ is real, so $\operatorname{Re}\mu = \langle A\rangle$ and $\operatorname{Im}\mu = -\lambda\langle B\rangle$. Substituting $\mu = \langle A\rangle - i\lambda\langle B\rangle$ into $(\hat A - i\lambda\hat B - \mu)|\psi\rangle = 0$ gives $(\hat A - \langle A\rangle)|\psi\rangle = i\lambda(\hat B - \langle B\rangle)|\psi\rangle$.

(b) In the notation of Theorem 3.7 this is $|f\rangle = i\lambda|g\rangle$. Cauchy–Schwarz is an equality for parallel vectors. And $\langle f|g\rangle = \overline{i\lambda}\langle g|g\rangle = -i\lambda\sigma_B^2$ is purely imaginary, so dropping the real part (step 3) loses nothing. Both inequalities in the proof are equalities, so (3.17) holds with equality; the covariance $\operatorname{Re}\langle f|g\rangle$ is zero, so B2(a) is also an equality. (`project.py` Part 5: an eigenvector of $A - 0.7iB$ gives ratio $1.000000000000$.)

(c) $\hat x + \frac{i}{m\omega}\hat p = \sqrt{\frac{2\hbar}{m\omega}}\,\hat a$ with $\hat a = \sqrt{\frac{m\omega}{2\hbar}}\big(\hat x + \frac{i\hat p}{m\omega}\big)$, and $\hat A - i\lambda\hat B$ with $\lambda = -1/m\omega$ is exactly $\hat x + i\hat p/m\omega$. So the saturating states are the eigenvectors of $\hat a$: coherent states $|\alpha\rangle$ (Example 4.6). In position space the condition is (3.19) with $a = m\omega$, a Gaussian of variance $\hbar/2m\omega$, so $\sigma_x = \sqrt{\hbar/2m\omega}$ for all $\alpha$. **B4.** (a) Let $\Delta\hat x = \hat x - \langle x\rangle$, $\Delta\hat p = \hat p - \langle p\rangle$ at $t = 0$. In the Heisenberg picture the state is fixed and $\hat x_H(t) - \langle x(t)\rangle = \Delta\hat x + \Delta\hat p\,t/m$. Square and average:

(b) For $\psi = (2\pi a^2)^{-1/4}e^{-(x - x_0)^2/4a^2 + ip_0x/\hbar}$: $\sigma_p = \hbar/2a$, and $\operatorname{cov} = 0$ (B2(b) with $c = 0$; the $e^{ip_0x/\hbar}$ factor and the shift change only the means). **B5.** (a) Expand in the mass basis: $\hat H = E_1|1\rangle\langle1| + E_2|2\rangle\langle2|$. With $c = \cos\theta$, $s = \sin\theta$:
$\langle\nu_e|\hat H|\nu_e\rangle = c^2E_1 + s^2E_2$, $\langle\nu_\mu|\hat H|\nu_\mu\rangle = s^2E_1 + c^2E_2$, $\langle\nu_e|\hat H|\nu_\mu\rangle = -csE_1 + csE_2$.

Then $c^2E_1 + s^2E_2 = \bar E - \delta(c^2 - s^2) = \bar E - \delta\cos2\theta$, the other diagonal entry is $\bar E + \delta\cos2\theta$, and the off-diagonal is $2cs\,\delta = \delta\sin2\theta$. In the basis $(\nu_e, \nu_\mu)$:
$\hat H = \bar E\,\hat 1 + \mathbf h\cdot\boldsymbol\sigma$ with $\mathbf h = \delta(\sin2\theta, 0, -\cos2\theta)$, $|\mathbf h| = \delta = \frac{(m_2^2 - m_1^2)c^4}{4pc}\approx\frac{\Delta m^2c^4}{4E}$.

**B6.** (a) Expand: $[\hat x, \hat T(a)] = \sum_{n\ge0}\frac{1}{n!}\big(-\frac{ia}{\hbar}\big)^n[\hat x, \hat p^n] = \sum_{n\ge1}\frac{1}{n!}\big(-\frac{ia}{\hbar}\big)^ni\hbar n\hat p^{n-1}$ by A4(b). Pull out $i\hbar\cdot(-\frac{ia}{\hbar}) = a$: the sum is $a\sum_{n\ge1}\frac{1}{(n-1)!}\big(-\frac{ia}{\hbar}\big)^{n-1}\hat p^{n-1} = a\hat T(a)$. So $\hat x\hat T = \hat T\hat x + a\hat T$; multiply on the left by $\hat T^\dagger$ (unitary, Theorem 3.11's argument with $\hat p$ in place of $\hat H$): $\hat T^\dagger\hat x\hat T = \hat x + a$. Then $\hat x\hat T|x\rangle = \hat T(\hat x + a)|x\rangle = (x + a)\hat T|x\rangle$, so $\hat T|x\rangle$ is a position eigenket with eigenvalue $x + a$; it has the same delta normalization (unitarity), so $\hat T(a)|x\rangle = |x + a\rangle$ up to a phase, which (3.31) fixes to $1$: $\langle x'|\hat T|x\rangle = \delta(x' - a - x)$.

(b) $\hat T^\dagger\hat p\hat T = \hat p$ (they commute), so $\hat T^\dagger\hat p^2\hat T = \hat p^2$. From (a), $\hat T^\dagger\hat x^k\hat T = (\hat T^\dagger\hat x\hat T)^k = (\hat x + a)^k$, so for $V$ given by a power series (or by (3.16) in general), $\hat T^\dagger V(\hat x)\hat T = V(\hat x + a)$. Hence $\hat T^\dagger\hat H\hat T = \hat H$, which is $[\hat T, \hat H] = 0$, if and only if $V(\hat x + a) = V(\hat x)$, i.e. (acting on $|x\rangle$) $V(x + a) = V(x)$ for all $x$.

(c) $\hat\Pi^2\psi(x) = \hat\Pi\psi(-x)\big|$ evaluated at $-x$ $= \psi(x)$, so $\hat\Pi^2 = \hat 1$. Hermitian: $\langle\phi|\hat\Pi\psi\rangle = \int\bar\phi(x)\psi(-x)dx = \int\bar\phi(-y)\psi(y)dy = \langle\hat\Pi\phi|\psi\rangle$ (substitute $y = -x$). Unitary: $\hat\Pi^\dagger\hat\Pi = \hat\Pi^2 = \hat 1$. Momentum: let $g = \hat\Pi\psi$, $g(x) = \psi(-x)$; $\hat pg = -i\hbar g'(x) = i\hbar\psi'(-x)$; applying $\hat\Pi$ gives $i\hbar\psi'(x) = -\hat p\psi$. So $\hat\Pi\hat p\hat\Pi = -\hat p$, and $\hat\Pi\hat p^2\hat\Pi = \hat p^2$. For even $V$, $\hat\Pi V(\hat x)\hat\Pi = V(-\hat x) = V(\hat x)$, so $[\hat\Pi, \hat H] = 0$. If $\hat H|n\rangle = E_n|n\rangle$ nondegenerately, Theorem 3.15 says $\hat\Pi|n\rangle$ is in the one-dimensional $E_n$ eigenspace: $\hat\Pi|n\rangle = c|n\rangle$, and $\hat\Pi^2 = \hat 1$ forces $c^2 = 1$, so $c = \pm1$.

(d) The double well has one symmetry, parity, which commutes with itself; Theorem 3.15's second part needs two non-commuting symmetries, and in 1D bound states are nondegenerate anyway. Parity only labels the states (the project finds $+, -, +, -$). On the ring both $\hat T$ (rotation by one site) and $\hat\Pi$ commute with $\hat H$ but $\hat T\hat\Pi = \hat\Pi\hat T^{-1}\ne\hat\Pi\hat T$; so some level is degenerate, and in fact $e^{\pm ikx}$ pair up (the project finds $0.4996$ twice and $1.99358$ twice).

**B8.** (a) From (3.6), $\langle p|x\rangle = \overline{\langle x|p\rangle} = (2\pi\hbar)^{-1/2}e^{-ipx/\hbar}$, so $i\hbar\,\partial_p\langle p|x\rangle = i\hbar(-ix/\hbar)\langle p|x\rangle = x\langle p|x\rangle$. Insert (3.4):

using $\langle p|\hat x|x\rangle = x\langle p|x\rangle$ ($\hat x$ acting to the right on its eigenket) and differentiating under the integral.

(b) $\langle p|\hat H|\psi\rangle = \frac{p^2}{2m}\Phi - F\,i\hbar\Phi'(p) = E\Phi$. This is first order: $\Phi' = \frac{-i}{\hbar F}\big(E - \frac{p^2}{2m}\big)\Phi\cdot(-1)$, i.e. $\frac{\Phi'}{\Phi} = \frac{i}{\hbar F}\Big(E - \frac{p^2}{2m}\Big)$. **C2.** (a) Take traces: $\operatorname{Tr}(XP) = \sum_{ij}X_{ij}P_{ji} = \sum_{ji}P_{ji}X_{ij} = \operatorname{Tr}(PX)$, so $\operatorname{Tr}(XP - PX) = 0$, while $\operatorname{Tr}(i\hbar I) = i\hbar N\ne0$.
